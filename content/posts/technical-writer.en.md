## Overview

AI-assisted development requires project context, rules, and requirements to carry across sessions. This article introduces the Technical Writer Skill, focusing on readers, usage scenarios, explanation order, and information density.

Examples include READMEs, API references, tutorials, and user guides, with an emphasis on preserving essential context and reducing repeated explanations.
