## 背景

随着 AI 技术的全面演进，智能体（Agent）已被广泛引入各垂直行业领域，用户通过简单问答即可快速获取信息，实现基础层面的效率提升。目前市面上多数垂直智能体大多停留在提示词工程微调（Prompt Fine-tuning）或基础知识库检索增强（RAG）阶段，对于复杂业务场景的实际赋能效果与泛化能力依然存在明显局限。

为此，自主研发的“火盘”定位于商业地产领域的企业级智能体系统，旨在精准匹配用户多元化、高复杂度的长链路信息需求，实现业务全流程的高效闭环与生产力提升。

## 方案与演进

商业地产任务涉及多种业态、专业数据与连续决策。火盘从复杂需求的任务编排出发，逐步完善工具能力、运行评测与领域模型，形成以下优势：

- **复杂任务编排。** 基于 LangGraph 实现 ReAct + Workflow 的 Agent 架构，能够处理用户的复杂长程需求，并兼容多种工具以实现复杂功能。
- **多模态工具能力。** 基于 DeepSeek 模型实现意图识别、多模态解析、图片处理及多 Agent 调用等工具能力，在提高任务完成度的同时减少 Token 消耗。
- **持续评测与迭代。** 基于 Langfuse 可观测性平台对系统进行多轮迭代，保障系统功能稳定性，并通过 A/B 测试优化与发布提示词，提升用户体验。
- **领域模型与数据查询。** 与行业专家深度合作，多轮迭代私有房产专业模型，基于 Tool Calling 技术实现 Text-to-SQL、需求深度挖掘等功能。

## 应用成效

火盘 Agent 已在市场洞察、AI 找房、创建房源等多个业务场景落地；同时已发布 MCP，在豆包、千问办公等应用中可通过 Skill 直接调用火盘助手。
